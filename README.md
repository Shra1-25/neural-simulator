# Rehearse Before You Act

Companion page for a research proposal: a neural simulator that learns physics to predict, intervene, infer and
explain. One example of each on held-out rubble piles, the physics engine (PhysX in NVIDIA Isaac Sim) next to the
neural simulator, plus how often the two agree.

Page: https://shra1-25.github.io/neural-simulator/

The site is static (`index.html`, `style.css`, `site.js`, `assets/`). It is served by GitHub Pages from the
`main` branch, root folder. The clips are made in the simagent repository (`scripts/unified/site_examples.py`,
`site_render.py`, `site_compose.py`).
